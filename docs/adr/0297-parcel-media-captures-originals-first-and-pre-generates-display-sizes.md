# ADR 0297: 필지 원천 사진은 원본을 먼저 확보하고, 표시 크기는 디자인이 정해지면 사다리로 미리 생성한다(임의 크기만 엣지 변환)

- Status: Accepted
- Date: 2026-10-25
- Builds on: [ADR-0290 §7](./0290-court-auction-details-are-refetched-by-change-and-sale-date-and-photos-are-content-addressed.md)(사진은 내용 해시로 한 번만 저장), [ADR-0296](./0296-public-auction-serves-full-info-and-shares-one-content-addressed-media-store.md)(공매 전체정보 서빙 + 경매·공매 공용 content-addressed 미디어 저장소), [FP-ADR-0016](../../platforms/foundation-platform/docs/adr/0016-bronze-commit-protocol.md)(Bronze 쓰기 관문)
- Amends: ADR-0296 — §2 가 저장·키·형식 판정까지 정했으나 **표시 크기(파생)·포맷·서빙/변환 방식**은 열어 두었다. 이 ADR 이 그 끝단을 정한다.

## Context

ADR-0296 §2 로 "사진을 내용 해시로 한 저장소에 한 번만 담는다"(공용 `media.rs`, 접두어 아래 `sha256/<해시>.<확장자>`, FP-ADR-0016 관문, 중복제거)는 정해졌다. 하지만 **화면에 어떤 크기·포맷으로 내보낼지**, 그리고 **웹 공매/경매 패널 디자인이 아직 확정되지 않았다는 사실**이 열려 있었다. 2026-10-25 사장과의 설계 대화로 이 끝단을 다음 사실 위에서 정했다:

1. **KAMCO 사진 URL 은 만료된다**(해시 `hashCrpsNo` 가 붙음, ADR-0296 §6). 받자마자 저장하지 않으면 사라진다 — 즉 **원본 확보는 디자인과 무관하게 지금 급하다.**
2. **표시 자리(슬롯) 크기는 디자인이 정하는데 아직 안 나왔다.** 슬롯은 원본 사진이 아니라 "우리 화면의 사진 박스"다(목록 썸네일·갤러리·전체보기). 사용자/원천이 아니라 우리 레이아웃이 정하므로, 확정되면 **소수의 고정 크기**가 된다.
3. **우리 스택은 Cloudflare(Workers + R2)** 이고 운영비 0 을 지향한다.
4. **대기업 정석**: 원본 한 벌 + 파생은 필요 크기만(Git/Docker/Nix 의 내용주소 저장 + Thumbor/imgproxy/Cloudflare/Imgix 의 크기 변환). 고정 크기는 미리 생성, 임의 크기는 즉석 변환 — 둘 다 **원본 하나 위**에서.

## Decision

1. **원본 우선(기준점). 수집 시 원본(제공된 최고 해상도) 1장을 반드시 content-addressed 로 보관한다**(만료 대비, 디자인 무관). **원본은 절대 버리지 않는다** — 이것이 어떤 서빙 방식으로도 나중에 전환 가능케 하는 유일한 기준이다. 사진만 저장하고 원본을 폐기하면 미래 크기 변경이 막힌다.

2. **표시 파생은 디자인이 확정되면 "크기 사다리"로 미리 생성한다(기본안).** 디자인이 정한 슬롯 크기(및 고해상도 배수 DPR)에 맞춘 **소수의 WebP 단계**(예: 160/320/640/1280)를 Rust 수집/파이프라인에서 **원본으로부터** 만들어 각각 content-addressed 로 저장한다. 브라우저는 `srcset`/`sizes` 로 제 화면·해상도에 맞는 단계를 고른다. 슬롯이 고정이라 사다리는 작고, **변환 수수료 0**(우리 서버에서 생성).

3. **들일 때 위생: 이미지의 EXIF(위치 등)를 제거하고 안전한 정규 포맷으로 재인코딩**한다. 감정평가서 PDF 는 원본을 보관하고, 첫 페이지 썸네일 여부는 후속 결정(지금 안 만듦).

4. **임의·미확정 크기는 엣지 on-the-fly 변환(Cloudflare Image Transformations)을 허용**한다 — 원본에서 즉석 변환. 쓰임: ① **디자인이 흔들리는 기간**에 미리 화면에 띄우고 싶을 때, ② **사람이 임의 레이아웃에 꽂는 미래 리소스 센터**처럼 슬롯을 미리 알 수 없을 때. 원본과 서빙 엣지를 사다리와 공유하므로 전환은 **가산적**(URL 패턴 + Worker 변환 단계 추가)이고, **하이브리드**(미리 만든 크기 있으면 그걸, 없으면 즉석 변환)도 허용한다. 원본을 클플에 중복 저장하는 "Cloudflare Images(저장 제품)"는 쓰지 않는다 — 저장은 R2 하나(SSOT).

5. **서빙·캐시.** 파일 이름이 곧 내용 해시이므로 사진 객체는 `immutable`, 1년 캐시로 내보내고 egress 는 0 이다. 사진 공개 URL 은 해시 기반 한 규칙으로 필지 엣지에서 서빙한다(ADR-0296 §5 와 정합, **새 호스트 없음**).

6. **미디어 backbone 수렴(SSOT).** 경매·공매·(미래) 사람 큐레이션 리소스 센터가 **모두 같은 content-addressed 저장소 하나**를 공유한다(ADR-0290 §7 / ADR-0296 §2 의 일반화). producer 는 둘(기계 수집 + 사람 어드민)이지만 저장·서빙·변환 경로는 하나다. 사람이 쓰는 통합 어드민(더니어, consoles/dawneer)은 **필요해질 때 그 위에 얹는다**(지금 만들지 않는다).

7. **비용 모델(기록).** data.go.kr API·KAMCO 다운로드는 무료(쿼터·시간만 듦). 실비는 R2 저장(원본 + 작은 파생 — 추정 월 ₩1~2만, **첫 수집에서 실측**). 엣지 변환은 쓰는 만큼(월 5,000건 무료, 이후 1,000건당 $0.50) — 기본안(미리 생성)은 변환료 0.

8. **SSOT.** 미디어 키·형식 판정 = `media.rs`(공용), 파생 사다리 규격 = 서빙 계약(공매 by-PNU v2), 원천 = `public-source-endpoint-catalog.v1.json`, Bronze 쓰기 = FP-ADR-0016. 한 사실 한 곳.

## Consequences

- **디자인이 안 나왔어도 수집(원본 확보)은 진행할 수 있다** — 만료 리스크 제거가 최우선이고 디자인과 무관하다(ADR-0296 Stage B 는 Stage D 웹과 분리).
- 디자인 확정 뒤 사다리 생성·서빙 전환은 재굽기지만, 원본을 들고 있으므로 **외부 의존 0** 으로 언제든 다시 만든다.
- on-the-fly ↔ 미리 생성 전환이 가산적·하이브리드라 **저위험**이고, 새 포맷(AVIF)·새 크기 추가도 선택지로 열린다.
- 미디어가 한 backbone 으로 수렴해 경매·공매·리소스 센터가 저장소를 중복하지 않는다.

## Alternatives rejected

- **Cloudflare Images(저장 제품)** — 원본을 클플에 중복 저장 → SSOT 위반. 기각(저장은 R2, 변환만 필요 시 Cloudflare Image Transformations).
- **imgproxy 상시 서비스** — 서버 1대 운영·보안 패치 부담(이미지 디코더는 취약점 단골), 우리 규모·클플 스택에 과함. 기각(필요 시 Cloudflare 변환으로 충분).
- **원본 안 받고 사진 URL 만 서빙** — 만료로 깨짐. 기각(ADR-0296 §Consequences).
- **파생만 저장하고 원본 폐기** — 미래 크기·포맷 변경 불가. 기각 — 원본 보관이 기준점(§1).
- **디자인 확정 전 사다리 크기 못 박기** — 슬롯 미정이라 추측이 됨. 기각 — 디자인 뒤로 미룬다(원본 보유라 손해 없음).

## Open

- 실제 사진 보유율·평균 용량·PDF 용량 → **첫 수집에서 측정**(ADR-0296 §B 와 동일, 지어내지 않는다).
- 디자인 확정 시 슬롯 크기·사다리 단계(및 DPR 배수)·크롭 규칙 → 서빙 v2 계약에 못 박는다.
- **수집 enable(=실비 발생·attended)은 운영자/사장 승인 사안**이다. 이 ADR 은 전략 결정이고, 실행 go 는 별도다(출시 전 돈 드는 대량작업은 금액·승인 후).
- 감정평가서 PDF 의 첫 페이지 썸네일 생성 여부.
