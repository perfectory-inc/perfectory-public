# ADR 0469: 사업지구의 블록·가지번은 지번이 아니고, 분양권은 자기 연결 하한을 가진다

- Status: Accepted
- Date: 2026-11-09
- Builds on: ADR-0349 §6(실거래 Silver 의 연결률 하한: 가려지지 않은 지번 가운데 현재 필지를 못 찾은 몫이 0.25 를 넘으면
  싣고 실패), ADR-0288(한 해석기)

## Context

**사고 (2026-11-09).** `foundation-rt-molit-silver-load.service` 가 15:42Z·16:21Z(그리고 그 전 매시) 실패했다. 실패 줄은
`1 object(s) linked fewer unmasked lots than the contract's bound; loaded, failing so it is seen` 이다. 행은 실렸다. 실패는
OnFailure 알림과 함께 그 run 의 출력 사건을 막는다: 실거래 Gold 는 이 Silver 가 바뀌었다는 것을 듣지 못한다.

journal 의 요약 줄은 잘려 있어(`run.log` 는 서비스 사용자만 읽음) 어느 객체인지는 Silver 에서 다시 쟀다(읽기 전용 Trino,
`silver.real_transaction` 의 현재 행):

| 데이터셋·달 | 가려지지 않은 지번 | 못 찾음 | 몫 |
|---|---|---|---|
| 분양권(`apartment_presale`) 2026-10 | 1,982 | 697 (`parcel_absent` 355, `unparsed` 342) | 35.2% |
| 분양권 2026-09 | 2,088 | 634 (322, 312) | 30.4% |
| 그다음 가장 높은 것(상업업무 2026-10) | 2,456 | 526 | 21.4% |

매시 run 이 분양권의 한 달을 실으므로 매시 실패한다. `unparsed` 의 모양(모든 적재 2,512 행): `…BL…`·`블록` 910 행(택지개발지구의
블록, `BL-A3`·`3BL`·`지구BL B-1`), `가-…` 1,598 행(도시개발·환지 사업의 가지번), 나머지 4 행. 둘 다 **지번이 아니다**: 제공자는
지번을 가리지 않았지만 지번을 주지도 않았다. ADR-0349 §6 의 0.25 는 공장창고·상업업무·아파트·연립·오피스텔 4,925 행에서 쟀고
(99.7% 연결), 분양권은 잰 적이 없다. 분양권은 단지의 필지가 생기기 전에 거래된다: 그 지번은 다시 나뉘기 전의 땅이라 현재 필지에
없는 것이 정상이다(`parcel_absent`).

## Decision

1. **블록과 가지번은 지번이 아니다.** `rt_molit_real_transaction.lot_of` 는 `BL`·`블록` 을 담은 값을 `block_lot`, `가-` 로
   시작하는 값을 `provisional_lot` 으로 적는다(이전에는 `unparsed`). 둘은 `jibun_masked`·`no_jibun` 과 함께 `NOT_A_LOT` 이고,
   하한은 이것들을 세지 않는다(`unmasked_lots`). 행에 남는 이유가 정확해진다. `12 -3` 처럼 붙임표 둘레의 빈칸은 지번으로 읽는다.
2. **잰 데이터셋은 자기 하한을 가진다.** 계약 `silver_load.max_unmasked_unresolved_share_by_dataset` 이 데이터셋별 하한을
   적고(지금 `real_transaction_apartment_presale` 0.5, 이유는 `…_reason` 에 잰 값으로), 없는 데이터셋은 0.25 그대로다
   (`link_bound`). ADR-0349 §6 이 말한 "첫 적재가 하한을 정한다" 를 분양권에 한 것이다.
3. 이미 실린 행은 고치지 않는다(append-only). 같은 달이 다시 실리면 바뀐 내용만 새 판으로 쌓이고, 이유 열이 바뀐 행도 그때
   새 판이 된다.

## 버린 대안

- **하한을 모두 0.4 로 올리기.** 다른 데이터셋에서 연결이 깨진 것(2026-10-30 이전의 해석기 사고 모양)을 못 본다.
- **분양권을 하한에서 빼기.** 분양권의 연결이 모두 깨져도(몫 1.0) 아무도 모른다. 0.5 는 그것을 잡는다.
- **블록을 사업지구 필지로 해석하기.** 블록 번호와 준공 뒤 지번을 잇는 원천이 없다(국토부 실거래 원천에도 없음).

## Consequences

- 고친 뒤의 몫(같은 행으로 계산): 분양권 2026-10 21.6%(355 / 1,640), 2026-09 18.1%(322 / 1,776), 2026-11(진행 중) 30.3%(33 / 109),
  모두 0.5 아래. 다른 데이터셋·달(지번 50 개 이상)은 모두 21.4% 이하라 0.25 아래. 매시 실패가 멈춘다(계산값, 다음 run 에서 확인).
- 비용 0: 정규식 두 개.
- 시험: `infra/lakehouse/spark/tests/test_rt_molit_real_transaction.py`(블록·가지번 7 모양, 블록 400 행이 하한을 깨지 않음,
  분양권의 하한과 나머지의 하한).
