# ADR 0348: 실거래가는 rt.molit.go.kr 벌크 내보내기로 받고, 최근 달은 계약해제가 들어오는 동안 다시 받는다

- Status: Accepted
- Date: 2026-10-30
- Builds on: [FP-ADR-0020](../../platforms/foundation-platform/docs/adr/0020-real-transaction-bronze-source-strategy.md)
  (실거래 원천의 기본 채널은 `rt.molit.go.kr` CSV export, API 는 동등성 확인용),
  [ADR-0281](./0281-court-auction-is-collected-openly-politely-and-stops-when-refused.md) (공개적으로, 예의 바르게,
  거절되면 멈춘다), [ADR-0300](./0300-every-hygiene-family-is-adopted-reconciliation-is-the-spine.md) H (run 마다 상한),
  [ADR-0314](./0314-partial-processing-is-the-default-and-full-is-a-contract-exception.md) (부분이 기본)

## Context

사장이 미수집 원천 전부의 수집을 승인했다(2026-10-30). 실거래가 12종 중 공장창고·토지·상업업무용이 산업용
부동산에 핵심이다. FP-ADR-0020 이 벌크 채널(`rt.molit.go.kr` 조건별 자료제공 CSV)을 정했고, 그 내보내기 코드
(`rt_molit_real_transaction_export_*`)가 있다. 하지만 정기 수집 작업이 없어서 운영 Bronze 는 0 이었다(읽기 전용 psql).

`rt.molit.go.kr` 이용안내에는 다음 문장이 있다. "기술적 수단(스크래핑, 캡처, 크롤러, 미러링 등 데이터 추출 프로그램
및 기타 자동화 수단)을 이용하여 본 사이트의 콘텐츠에 엑세스하는 행위" 를 금지하고, "데이터의 대량·반복적인 이용이
필요할 경우, 공공데이터포털(www.data.go.kr)에서 제공하는 국토교통부_실거래가 정보를 이용" 하라고 한다.

**사장 결정 2026-10-30: 이용안내 자동화 조항을 인지하고 벌크 경로 유지.** 사장은 그 조항을 읽고 그 사업 위험을
진다. API 파이프라인은 만들지 않는다. 벌크가 하나뿐인 정본이다. 넘지 않는 선은 그대로다. CAPTCHA·로그인·접근
통제를 우회하지 않는다. 그런 것이 나오면 멈추고 보고한다.

**사장 결정 2026-10-31: 새벽 창과 느린 간격은 두지 않는다.** 아무 때나 보통 속도로 받는다. 대신 실용적인 안전장치
세 가지를 둔다.

- 동시 내려받기는 2–4건으로 적게 한다.
- 5xx·429 는 늘어나는 간격으로 다시 묻는다.
- 사이트가 분명히 거절하기 시작하면 멈추고 경보를 낸다.

2026-10-30 실측(예의 바른 몇 번의 요청, 5초 간격):

| 사실 | 값 |
|---|---|
| 접근 | CAPTCHA 없음, 로그인 없음. 내보내기 양식 페이지가 세션 쿠키를 주고, 개수 확인(JSON)과 CSV(POST)가 뒤따른다 |
| 전국 한 번의 범위 | 최대 1개월: "전국 자료제공 계약일자 범위는 최대 1개월입니다." |
| 행 수 상한 | 없음: 2025-09 아파트 전월세 전국 95,786행, 18 MB, 8초 |
| 하루 내려받기 한도 | 100건: 제공자의 개수 확인 답 "일일 다운로드 횟수는 최대 100건 입니다."(내보내기 코드의 시험이 이미 인용) |
| 신선도: 벌크 대 data.go.kr API | 같다. 2026-10 공장창고 시흥 8행·최신 계약일 10-15, 김포 12행·10-28 이 양쪽 동일하다. 2025-09 전국 아파트 전월세 95,786, 아파트 매매 49,880, 토지 30,098 도 양쪽 같다. 벌크의 지연은 0일이다 |

## Decision

1. **실거래가 12종의 유일한 정본은 `rt.molit.go.kr` 조건별 자료제공의 전국 월 CSV 다**(FP-ADR-0020 의 채널).
   data.go.kr RTMS API 로는 정기 수집하지 않는다. 엔드포인트 카탈로그의 API 항목은 `disabled_api_duplicate`
   그대로다. 수집 단위는 (데이터셋, 계약 달) 하나의 전국 내보내기다. 제공자는 전국을 한 달씩만 주고 그 달의 행을
   전부 준다.

2. **속도와 안전장치(사장 결정 2026-10-31).**
   - 세션 하나에 내려받기 3건이 동시에 돈다. 각 요청 앞에 1초를 둔다.
   - 시간 창은 없다.
   - run 당 30건, KST 하루 90건까지다. 제공자 한도 100건에서 사람 몫을 남긴다. 이력의 속도를 정하는 것은 우리 속도가
     아니라 이 하루 한도다.
   - User-Agent 는 우리 이름이다(`perfectory-foundation-rt-molit/1`, ADR-0283). 프록시·회전·브라우저 위장·무작위는
     없다. 수집기 소스를 읽는 시험이 이를 지킨다.
   - 계약 `rt-molit-real-transaction.contract.json` `manners` 가 값을 쥔다.

3. **바쁨은 다시 묻고, 분명한 거절이면 멈추고, 사람이 풀기 전에는 다시 묻지 않는다.**
   - 바쁨(HTTP 429·5xx, `RtMolitBusy`)은 30초부터 두 배씩 늘어나는 간격으로(최대 300초) 3번까지 다시 묻는다.
   - 분명한 거절은 HTTP 403, 또는 JSON·CSV 자리에 온 HTML(차단·공지·로그인·CAPTCHA 페이지, `RtMolitRefusal`)이다.
     재시도를 다 쓰고도 바쁜 것도 거절로 본다.
   - 거절이면 그 run 을 끝내고 `refused.json` 을 남긴다. 그 파일이 있는 동안 모든 run 은 요청 없이 실패한다(경보).
   - 제공자의 하루 한도 답은 거절이 아니다. 다음 KST 날까지 기다린다.
   - 그 밖의 제공자 오류(예: 1개월 초과)는 우리 잘못이므로 run 의 실패다.

4. **다시 받는 주기는 잰 해제 지연으로 정한다.** 계약 달의 나이는 이번 KST 달을 0 으로 센다.

   | 나이 | 다시 받는 주기 | 이유 |
   |---|---|---|
   | 0–2 | 매일 | 신고 기한 30일 + 그 달 거래가 들어오는 중. 해제 31% 가 30일 안 |
   | 3–12 | 매주 | 해제의 p99 354일 |
   | 13–24 | 매달 | 해제 최댓값 442일 |
   | 25+ | 처음 한 번만 | 그 뒤는 다시 받지 않는다 |

   "이번 달과 앞의 2–3 달만" 다시 받으면 해제의 57%(90일 안)만 잡는다. 이 주기는 하루 약 58건을 쓴다
   (36 + 17 + 5, 계산). 나머지 약 32건/일이 이력을 받는다.

5. **처음 받는 달(이력)의 순서.** 다시 받기 뒤에, 공장창고·토지·상업업무용 먼저, 새 달부터 받는다. 이력은 2,760개
   달이다(계산). 산업용 세 종(약 750개 달)은 약 23일, 전부는 약 86일 걸린다. 운영자가 지켜볼 창은 필요 없다.
   이력도 2번의 상한 안에서 밤마다 조금씩 간다.

6. **Bronze 는 덧붙이기만, 내용 주소로.** 객체 키는 `.../period=<YYYY-MM>/scope=nationwide/export--sha256-<hex>.csv`
   (ADR-0152 의 키 모양)다. 다시 받은 달의 바이트가 같으면 쓰지 않는다. 다르면 옛 객체 옆에 새 객체로 남는다.
   제공자 CSV 바이트(CP949, 안내문 머리 포함)는 바꾸지 않는다(FP-ADR-0020). 상태는 내보내기마다 저장되므로
   멈춘 run 은 받던 한 건만 잃는다.

## Consequences

- 작업:
  - `rt_molit_real_transaction_collect`: default_pool, 매시 25분.
  - `rt_molit_real_transaction_silver`: spark 1칸, ADR-0349.
  - 상태는 `/var/lib/foundation-platform/real-transaction` 에 둔다.
  - 키가 필요 없으므로 사장이 할 일이 없다.
- 양과 비용(계산):
  - 이력은 약 6천만 행이다. 전국 CSV 는 행당 약 190B 이므로 원본은 약 11GB 다.
  - 다시 받기는 바뀐 달만 쓴다. 최근 3개 달의 하루 재받기 상한은 약 160MB/일이다. 실제로는 그날 바뀐 달만 쓰인다.
  - 연 100GB 를 넘지 않는다. R2 $0.015/GB·월로 1년 뒤 월 $1.5 안팎, 5만 원/월 문턱에 한참 못 미친다.
- 위험: 제공자가 자동 접근을 막으면(차단 페이지·429) 3번이 수집을 멈추고 경보를 낸다. 그때 경로는 사장이 다시
  정한다. 우회는 하지 않는다.
