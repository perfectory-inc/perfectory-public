# ADR 0299: 엔지니어링·운영 위생은 기계로 강제되는 불변식이다 — 분류·우리 현황·채택/보류

- Status: Accepted
- Date: 2026-10-26
- Builds on: [AGENTS.md 최상위 원칙](../../AGENTS.md)(근본 해결·SSOT·재발 불가), [ADR-0004 검증 SSOT](./0004-verification-ssot.md)(정본 하나를 로컬·CI 가 같이 부른다), [ADR-0005 훅은 조언 CI 가 권위](./0005-hooks-advisory-ci-authoritative.md)
- 관련 실사례(이 결정을 촉발): [ADR-0298](./0298-content-addressed-media-is-a-write-once-store-not-a-per-object-bronze-ledger.md) 미디어 쓰기 경로, 그리고 2026-10-26 사진 100% 실패(`foundation-outbox` `read_object_sha256` 가 404 를 `Err` 로 매핑, 형제 `read_object_sha256_and_size_by_rehash` 는 `Ok(None)` — 같은 R2 클라이언트의 not-found 처리 불일치).

## Context

소유자는 **SSOT·일관(consistency)·일률(uniformity)** 을 "위생(hygiene)" 으로 — 기능 정확성과 별개로, 어기면 그 자체가 결함인 기본 청결로 — 본다. 이 셋은 더 큰 **엔지니어링·운영 위생** 의 한 귀퉁이(구조 위생)다. 성숙한 조직은 그 위생을 사람이 기억하는 규율이 아니라 **기계가 강제하는 불변식**(CI 게이트·정책 as code·필수 대시보드/경보·릴리스 게이트·스캐너)으로 유지한다.

세 단어를 분해해 이 저장소의 용법을 고정한다:

- **SSOT**: 한 사실은 한 곳에만 산다(값·경계·용도는 계약 JSON, 결정은 ADR). "선언은 한 번."
- **일관(consistency)**: 서로 맞아야 할 것이 어긋나지 않는다 — 선언한 것과 실물이 같다. 분류상 **G 계열(정합/드리프트 감지)** 이 정중앙이다(desired 를 선언하고 actual 과 지속 대조·수정하는 컨트롤러 패턴).
- **일률(uniformity)**: 같은 종류의 일은 **예외 없이 같은 방식**으로 한다. 이것은 한 계열이 아니라 **"모든 X 는 Y 하고, 안 하면 가드가 거부한다"** 라는 **적용 성질**이라, 아래 여러 계열의 규칙에 공통으로 얹힌다.

세 단어는 한 축의 3 단계다: **선언을 한 번(SSOT) → 실물을 그와 같게(일관) → 모든 인스턴스에 예외 없이(일률).**

2026-10-26 대기업 1 차 자료 조사(Google SRE Book / SWE at Google, SLSA, OWASP ASVS, 12-Factor, SemVer, Keep a Changelog, OpenSSF Scorecard, Kubernetes reconciliation)와 저장소 전수감사로 아래 분류와 우리 현황을 얻었다. 핵심 교훈: **규칙 문장만으로는 위생이 지켜지지 않는다. "규칙(값은 계약) + 가드(미준수 CI 거부) + 수렴(기존을 계약으로)" 세 층이 다 있어야 한다.** 가드가 수렴을 강제한다(미준수가 빨간불); 수렴 작업 자체는 사람이 한다.

소유자 규모(1 인 운영·출시 전·공개 저장소)에서 [AGENTS.md §6](../../AGENTS.md)("대기업식 ≠ 서비스 남발, 우리 규모에 맞는 보장만")대로, 15 계열 전부를 지금 규칙으로 박지 않는다. **지금 채택(가드까지) / 사유 달고 보류(트리거 명시)** 를 가른다.

## Decision

**1. 위생은 기계로 강제되는 불변식이다. 가드(또는 CI 게이트) 없는 위생 규칙은 규칙이 아니라 조언이며, AGENTS.md 에 넣지 않는다.** 새 위생 규칙은 정본 하나(계약/설정) + 그 준수를 검사하는 가드를 함께 남긴다([ADR-0004](./0004-verification-ssot.md) 패턴).

**2. 아래 15 계열 분류를 참조 카탈로그로 채택한다**(A~O). 모든 위생 논의·감사·규칙은 이 분류 위에서 한다.

| 계열 | 포함(요지) |
|---|---|
| A 관측성 | 구조화 로그·메트릭(/metrics)·분산 트레이싱·카디널리티 규율 |
| B SLO | SLI/SLO·에러버짓을 릴리스 게이트로 |
| C 경보·온콜 | 증상 기반 경보·무음실패 방지(데드맨)·경보마다 런북 |
| D 사고관리 | 무비난 포스트모템·추적되는 조치항목 |
| E 배포안전 | 카나리·자동 롤백·마이그레이션 expand-contract |
| F 변경관리 | CODEOWNERS 필수리뷰·선형/컨벤셔널 이력 |
| **G 정합(일관)** | 선언 desired==actual 지속 수렴·IaC 드리프트 감지 |
| H 데이터품질·계약 | 경계 검증·스키마 호환성·멱등성/전달의미 |
| I 공급망·보안 | SBOM/프로비넌스(SLSA)·핀고정+취약점스캔·비밀 회전·최소권한·감사로그 |
| J 용량·성능 | 용량/부하시험·성능예산·자원 한계·쿼터 |
| K 백업·DR | 리허설된 복원·DR 게임데이 |
| L 테스트위생 | 커버리지 게이트·플레이크 격리·헤르메틱/재현 빌드 |
| M 문서·버전·수명 | 문서 최신성·체인지로그·SemVer+폐기정책·기능플래그/킬스위치 |
| N 회복탄력성 | 타임아웃+제한된 재시도·우아한 종료 |
| O 운영 횡단 | config-in-env/build-once·비용(FinOps)·보존·PII·접근성·i18n·고아정리·소유권 |

**3. 지금 채택(규칙+가드까지 간다)** — 우리 규모에 비용 대비 가치가 높고, 대부분 일관/일률 결함을 이미 드러낸 것:

| # | 규칙(불변식) | 가드/메커니즘 | 우리 현황·근거 |
|---|---|---|---|
| H-cap | 모든 수집 job 은 run 당 한도(항목/바이트)를 **하나의 통일된 어휘로** 계약에 선언한다 | 새 가드: 미선언 수집 job CI 거부. 상한 어휘 통일(지금 `max_requests_per_run`/`per_run_limit`/`daily_download_limit` 3 종) | 10-26 공매 timeout; 지금 시간상한만 일률 |
| C-host | 호스트는 파티션 여유·inode·메모리를 노출하고 임계에서 경보한다 | node_exporter+cadvisor Prometheus 타깃 + 디스크/메모리 룰 | 지금 자원 텔레메트리 0(디스크풀/OOM 반복이 런타임 경보 없음) |
| A-metrics | 장기 실행 서비스는 /metrics 를 노출하고 스크랩된다 | 스크랩 타깃에 outbox·수집기·identity·tile 추가 | 지금 foundation-api 단일 타깃 |
| K-restore | 운영 DB 는 백업 freshness 경보 + 정기 복원 드릴을 가진다 | postgres 복원드릴 systemd 타이머 + backup-freshness 유닛(identity 대칭) | postgres 복원드릴 스크립트에 타이머 없음(수동), freshness 유닛 없음 |
| G-recon | content-addressed 객체 저장소는 인벤토리 대비 색인 대사·고아 정리를 가진다 | R2 onbid/media·타일 인벤토리 vs silver 색인 대사 잡 | Iceberg 만 orphan GC; 객체 저장소 대사 없음 |
| E-migrate | 스키마 변경은 expand→backfill→contract. 필수열-무백필·단일 DROP/rename 거부 | `migration-approval-gates.py` 확장(지금 DROP 만) | #469 필수열-무백필 무가드 |
| F-owners | main 은 CODEOWNERS 경로별 ≥1 리뷰를 요구한다 | `main-ruleset.json` 승인수·code-owner review + CODEOWNERS 파일 | 지금 필수리뷰 0·CODEOWNERS 없음 |
| L-lint | 모든 JS 영역은 공유 Biome 설정으로 린트되고 경고가 CI 를 막는다 | 루트 공유 biome config + `--error-on-warnings` | 지금 gongzzang 만·경고 비차단 |
| O-env | 환경 설정은 env SSOT(`lib/env.ts`)로만 읽는다; 날 `process.env` 금지. 버전 핀은 버전 계약 안 | `no-env-access` 가드 확장 + OpenNext/wrangler 를 `technology-versions.contract.json` 로 | 날 `process.env`·OpenNext 핀이 계약 밖 |

**급한 3 개(소유자 결정)는 공매와 병행**: C-host, K-restore, H-cap. 나머지 채택분은 공매가 화면까지 끝난 뒤.

**4. 사유 달고 보류(트리거에서 재검토)** — 우리 규모에 아직 과하거나 외부 비용/의존이 큰 것:

| 보류 | 사유 | 재검토 트리거 |
|---|---|---|
| B 에러버짓/burn-rate 릴리스 게이트 | SLO 가 아직 tripwire(`slo-alert-policy.md`); 트래픽 적음 | 유료 트래픽·다중 서비스 |
| C 외부 호출기(슬랙 넘어 페이저) | 출시 전·1 인; 지금 슬랙으로 충분 | 유료 사용자 24/7 서빙 |
| I SBOM+SLSA 프로비넌스 | 서명+락파일로 지금 충분; 소비자 없음 | 외부 배포·공급망 요구 |
| I CodeQL/SAST | 공개 저장소 무료라 비용 0 → **가벼워 곧 채택 후보**(지금은 보류 목록에 사유와 함께 둔다) | 다음 위생 라운드 |
| E 카나리(API) | 단일 호스트; 타일 게이트웨이만 카나리 보유 | 다중 레플리카·무중단 요구 |
| K DR 게임데이·L 헤르메틱 재현빌드·A 분산트레이싱·M 기능플래그 시스템 | 규모 대비 과함 | 다중 리전·서비스 급증 |

**5. 채택분은 AGENTS.md `## 위생 불변식` 절에 크리스프 규칙 한 줄 + 가드 이름 + 이 ADR 링크로 들어간다.** 보류분은 이 ADR 표에만 사유와 함께 남는다(규칙 파일엔 넣지 않는다 = 일률: 강제 못 하는 건 규칙이 아니다).

## Consequences

- 위생이 "문서에 적힌 바람" 이 아니라 **가드로 빨간불 나는 불변식** 이 된다. 새 수집 job·새 서비스·새 JS 영역은 해당 가드를 통과하지 못하면 머지되지 않는다.
- 기존 위반(상한 어휘 3 종, 미린트 영역, env 드리프트, not-found 처리 불일치 등)은 가드가 **수렴을 강제**한다 — 초록불 유지가 곧 청소다.
- 분류(A~O)가 생겨 앞으로 모든 감사가 같은 틀 위에서 비교된다(일률).
- 보류분은 사라지지 않고 트리거와 함께 추적된다 — 우리 산출물을 대기업급이라 자평하지 말고 "비교조차 하지 않은 축" 을 명시하라는 소유자 지침을 따른다.

## Alternatives rejected

- **15 계열 40 규칙을 지금 전부 AGENTS.md 에 박기** — 가드 없이 규칙만 늘리면 조언이 쌓일 뿐이고(일률 위반), 우리 규모에 과한 것(DR 게임데이 등)까지 강제해 소음이 된다. 기각.
- **규칙만 적고 가드는 나중에** — 가드 없는 규칙은 다음 사람이 어겨도 안 막힌다(바로 공매 사고·not-found 불일치가 그렇게 생겼다). 기각: 규칙과 가드는 한 PR 에서 함께 간다.
- **감사 결과만 백로그에 두고 ADR 안 만들기** — 분류·채택/보류 결정이 장수하는 결정이라 ADR 이 정본이어야 한다(AGENTS.md 규칙이 가리킬 대상). 기각.

## Open

- 각 채택 규칙의 가드 구현·임계값은 그 규칙의 PR 에서 확정(예: 디스크 여유 경보 임계, 커버리지 바닥, 상한 어휘의 정확한 스키마).
- 상한 통일 어휘(H-cap)의 스키마 — 지금 3 종 키를 하나로 모을 형태 — 는 그 가드 PR 에서 "새 메커니즘 전에 증명"([AGENTS.md 해결 접근 순서](../../AGENTS.md)) 뒤 결정.
- CodeQL(I-SAST)은 공개 저장소 무료라 다음 라운드에서 보류→채택으로 옮길 유력 후보.
