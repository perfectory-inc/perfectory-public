# ADR 0121: 코드는 실제로 본 원천 글자만, 원천이 나눈 만큼 나눠, 원천의 뜻대로 이름 붙인다

- Status: Accepted
- Date: 2026-10-01
- Builds on: [ADR-0117](./0117-metadata-has-one-contract-per-dataset-and-one-place-to-look.md) §5(원본 글자 칸),
  [ADR-0120](./0120-a-changed-derivation-appends-the-same-source-object-once-more-under-its-label.md)(다시 파생)

## Context

산업단지 프로필(VWorld `TB_IRSTT_BASS_HIST`, 202506, 1,442행)의 조성 상태 `make_sttus_nm` 은 실측상 네 글자뿐이다.

| 원천 글자 | 행 | 착공일 있음 | 준공일 있음 | 조성공정율 |
|---|---:|---:|---:|---|
| 조성완료 | 1069 | 1069 | 1069 | 91~100 |
| 조성중 | 289 | 289 | 1 | 0~100 (평균 59.9) |
| 준비중 | 47 | 43 | 0 | 0 |
| 보상중 | 37 | 37 | 0 | 0 |

2026-08-17 (#80) 의 대응표에는 세 가지 잘못이 들어갔다.

1. **본 적 없는 글자를 추측으로 넣었다.** `개발완료→operating`, `계획→planned` 등 상태 8개와 `국가산업단지→national` 등
   유형 5개가 "다른 달에 올지도 모른다"는 이유로 들어갔다. 코드 주석 스스로 "아무것도 확인하지 않았다"고 적었다. 그런
   글자가 오면 뜻을 아무도 확인하지 않은 채 적재된다.
2. **원천이 나눈 것을 합쳤다.** `준비중`과 `보상중`은 원천이 다른 단계로 적은 것인데 "둘 다 공정율 0"이라는 이유로
   `planned` 하나가 됐다. 원본 글자를 버렸으므로(ADR-0117 §5 이전) 다시 나눌 수도 없었다.
3. **코드 이름이 원천에 없는 뜻을 말한다.** `조성완료`의 코드가 `operating`(운영 중)이다. 원천은 부지 조성이 끝났다고만
   말한다. 화면이 이 이름을 번역해 "운영 중"이라 적은 일이 실제로 있었다(2026-09-30).

사용자 지시(2026-10-01): 추측하지 말고 대기업 수준으로 고친다.

## Decision

1. **대응표는 실측한 글자만 갖는다.** 추측(`*_PRESUMED`) 표는 지운다. 처음 보는 글자가 오면 적재는 행 번호와 함께
   멈추고, 사람이 그 글자의 뜻을 확인한 뒤 근거(스냅숏·행 수)와 함께 실측 표에 더한다.
2. **원천이 나눈 만큼 나눈다.** 서로 다른 원천 글자는 서로 다른 코드다. 둘을 합치려면 원천 기관이 같은 뜻이라고 밝힌
   근거가 있어야 하고, 그 근거를 대응표 옆에 적는다.
3. **코드 이름은 원천의 뜻을 말한다.** 조성 단계의 새 칸 `development_stage` 의 값은 다음 넷이다.

   | 원천 글자 | `development_stage` |
   |---|---|
   | 조성완료 | `site_completed` |
   | 조성중 | `site_in_progress` |
   | 준비중 | `preparing` |
   | 보상중 | `compensating` |

   `changed`·`abolished`·`unknown` 처럼 한 번도 관측되지 않은 값은 이 칸의 값 목록에 없다.
4. **넓혔다가 줄인다(expand–contract).** `development_stage` 를 Silver·Gold·기준정보 DB·API 에 더하고, 옛 `status` 는
   이번 변경에서 그대로 두되 API 에서 폐기 예정으로 표시한다. 더니어와 공짱이 `development_stage` 로 옮긴 뒤 별도 변경으로
   `status` 를 지운다. 원본 글자 칸(`status_raw`)은 그대로 남는다.
5. 유형(`lrstt_ty`)과 분양(`lttot_sttus_nm`)은 이미 실측 글자와 1:1 이고 이름도 원천의 뜻과 맞으므로 유형의 추측 표만
   지운다.

## Consequences

- 새 달의 원천에 처음 보는 글자가 있으면 그 달의 적재가 멈춘다. 의도된 동작이다.
- 기존 1,442행은 ADR-0120 의 파생 이름으로 한 번 더 쌓아 `development_stage` 를 채운다. 원본 글자 칸이 이미 있으므로
  원천을 다시 내려받을 필요는 없지만, 같은 경로(Bronze 재파생)로 채운다.
- 시험: 실측 표가 측정 기록과 정확히 같다는 시험이 남고, 추측 표의 존재를 전제한 시험은 지운다. `development_stage` 는
  `catalog_domain` 의 열거형이 값 목록의 주인이다.
