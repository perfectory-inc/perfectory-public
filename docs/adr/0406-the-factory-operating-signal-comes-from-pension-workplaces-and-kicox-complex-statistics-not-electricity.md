# ADR 0406: 공장 가동 신호는 전기 사용량이 아니라 국민연금 사업장과 KICOX 단지 통계에서 온다 — 원천 조사

- Status: Proposed
- Date: 2026-11-04
- Builds on: [ADR-0398](./0398-a-parcel-shows-twelve-months-of-building-energy-as-its-own-by-pnu-kind.md)
  (필지 건물 전기·가스 12개월), [ADR-0280](./0280-public-sale-court-auction-and-factory-registration-are-foundation-parcel-sources.md)
  (전국등록공장현황, 주소로 PNU), 산업단지 코드 정본(ILIS 단지, 메모리 "산단 코드 3종은 하나")

## Context

ADR-0398 의 건축HUB 에너지 파일(건물별 전기·가스 월 사용량)에는 **산업용이 빠져 있다.** 그래서 공장 필지에는
"공장이 돌고 있는가" 를 보여 줄 신호가 없다. 사장 지시(2026-11-04)로 공장·산업용 전력과 가스 사용, 가동 상태를
주는 공식 원천을 모두 찾았다. 조사만 했다. 코드는 없다.

조사 방법: 각 원천의 공공데이터포털 상세·카탈로그 JSON, 한전 전력데이터 개방포털 API 명세를 직접 읽었다
(2026-11-04). **파일은 하나도 내려받아 열지 않았다.** 아래 "확인 못 함" 은 샘플 한 번으로 풀어야 한다.

### 사실 셋

- **전기·가스로는 공장 하나를 볼 수 없다.** 공개 전력 자료의 가장 작은 단위는 시군구 × 산업 대분류다. 한전 고객
  단위 자료는 데이터안심구역 안에서만 분석할 수 있고, 반출은 분석 결과뿐이다. 가스는 시도가 가장 작다.
  산업용 전력을 필지에 붙이는 공개 경로는 없다.
- **"가동률" 숫자를 주는 공개 원천은 KICOX 산업동향 API 하나다.** `monthOpRate`(당월 가동률 %), `totalOpCmpnyCo`
  (가동업체 수), 생산능력 대비 생산액을 준다. 다만 공단이 관할하는 주요 국가산단만 다룬다. 단지 코드는 없다.
- **필지 단위로 가장 강한 가동 신호는 국민연금 사업장이다.** 사업장마다 매월 가입자 수, 신규 취득·상실 수, 탈퇴일을
  준다. 고용 추이와 탈퇴(폐업·휴업)가 곧 가동 여부다. 주소는 법정동까지라서 등록공장을 다리로 써야 한다.

## Decision (제안)

순위. 필지 화면과 단지 화면에 쓸 공장 가동 신호다.

| 순위 | 원천 | 화면 | 이유 |
|---|---|---|---|
| 1 | 국민연금 가입 사업장 내역 | 필지(공장) | 사업장별 월 고용과 탈퇴. 무료, 대량 파일 + API, 매월 |
| 2 | KICOX 산업동향 API 가동률 | 단지 | 공개 원천 중 유일한 가동률 %. 대상 단지가 적다 |
| 3 | KICOX 전국산업단지현황통계 | 단지 | 모든 단지. 가동업체 ÷ 입주업체가 가동률의 대리 지표 |
| 4 | 근로복지공단 고용·산재 | 필지(보조) | 연 1회라 느리다. 사업자번호가 10자리면 5번의 열쇠다 |
| 5 | 국세청 상태조회 | 필지(보조) | 폐업 확인. 10자리 번호 원천이 있어야 한다 |
| 6 | 한전 산업분류별 사용량·고객 증감 | 시군구 배경 | 지역 추세. 필지·단지에 붙지 않는다 |
| 7 | 한전 데이터안심구역 | 연구만 | 서빙 불가 |
| 8 | 가스·에너지다소비·광업제조업조사 | – | 너무 거칠다 |

1. **단지 가동률(2·3번)을 먼저 한다.** 우리는 단지 정본(ILIS 단지 코드)을 이미 가졌다. 원천에는 단지 코드가 없으므로,
   단지명(+시군) → 단지 코드 **대응표를 계약 정본**으로 둔다. 대응이 안 되는 이름은 조용히 버리지 않고 미대응으로
   센다(계약 SSOT, 새 원천 가드). 사장의 "모든 데이터 수집" 승인(2026-10-30) 범위다.
2. **필지 가동 신호(1번)는 다음이다.** 국민연금 월 파일을 append-only 로 쌓는다. 법정동 코드 + 사업장명 정규화 + 업종으로
   등록공장(PNU 보유)과 맞춘다. 맞춘 연결은 측정한 정밀도로만 쓴다(ADR-0351·0370 과 같은 원칙: 하한 99%).
   법정동 코드는 `views.changed_codes`(ADR-0329 §3)를 따라간다.
3. **전력·가스 사용량은 필지 신호로 쫓지 않는다.** 한전 산업분류별 API 는 시군구 배경 지표로만 검토한다.
4. 착수 전 샘플 한 번으로 확인한다(아래 "확인 못 함").

공공 통계 관행도 같다. 사업장의 가동과 생멸은 전력 미터가 아니라 고용·사회보험 행정자료로 본다. 미국 노동통계국
QCEW 는 실업보험(UI) 신고로 사업장별 고용을 센다. 인구조사국 Business Dynamics Statistics 는 급여 행정자료로 만든
사업자 등록부로 사업장의 생멸을 센다. 전력 미터 자료는 개인정보라서 한전처럼 안심구역 안에서만 쓰는 것이 보통이다.

## Consequences

- 공장 필지에 "가동 중" 을 보일 수 있는 길이 생긴다. 단, 1번은 이름 맞춤이라 정밀도를 재야 켤 수 있다.
- 단지 화면은 2·3번으로 곧 가동률·가동업체 수를 보일 수 있다. 대응표 정본을 새로 관리해야 한다.
- 비용: 모두 무료 공개 원천이다. 국민연금 파일은 월 한 판(수십만 행 규모로 추정, 확인 못 함)이다. 수집·적재는
  ai-server 에서 기존 원천과 같은 경로다. 새 유료 지출은 없다.
- **확인 못 함(샘플로 풀 것).**
  - 국민연금 파일 주소에 번지가 있는지, 사업자번호 자릿수(API 는 앞 6자리만 받는다)
  - 근로복지공단 파일의 주소 정밀도와 사업자번호 자릿수
  - KICOX 산업동향 API 가 다루는 단지 수, 실제 갱신 주기(분기인지 월인지)
  - 한전 개방포털 자체 약관
- 이 ADR 은 Proposed 다. 사장이 순위와 착수 순서를 정하면 원천별 계약·수집 ADR 을 따로 쓴다.
