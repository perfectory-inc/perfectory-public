# ADR 0144: 지역 코드 변경은 내려받은 데이터만으로 판단한다 — 게시판은 쓰지 않는다

- Status: Accepted
- Date: 2026-10-04
- Supersedes: [ADR-0143](./0143-legal-dong-code-changes-come-from-code-go-kr.md) §3 (코드변경안내 첨부를 짝의 1순위로 둔 결정)
- Related: [ADR-0113](./0113-parcel-lineage-absorbs-reorganizations-and-gates-every-map-bake.md) (필지 계보), [ADR-0142](./0142-hub-register-pnu-loss-is-refused-at-derivation-and-at-load.md)

## Context

ADR-0143은 code.go.kr을 법정동 변경의 정본으로 두면서 짝의 1순위를 **코드변경안내 게시판 첨부 엑셀**로 정했다.
소유자는 2026-10-04에 이를 거부했다.

- 게시판 공지는 사람이 올리는 글이다. 양식이 공지마다 다르다(엑셀·한글 문서·없음).
- 그래서 내려받는 데이터보다 신뢰도가 낮다.
- 시스템이 게시판에 의존하면 안 된다.

게시판 없이도 데이터로 판단할 수 있는지 실측했다.

| 경우 | 데이터 | 결과 |
|---|---|---|
| 번호만 바뀜 (2026-07-01 전남광주) | code.go.kr 전체 코드 표: 같은 날 폐지·생성 + 시도를 뺀 이름 | 3,205쌍 모두 하나로 정해짐. 게시판 엑셀의 쓸 수 있는 3,176쌍과 전부 일치 |
| 필지 번지 그대로 (전남광주) | VWorld 연속지적 7월·9월판: 같은 번지가 새 코드로 존재 | 6,315,425필지 중 6,303,927(99.82%)이 1:1 (2026-09-29 실측) |
| 동이 쪼개짐 (인천 옛 시천동) | 같은 자료의 번지 겹침률 | 시천동 겹침 37.8% → 분할 신호 (ADR-0113 §5) |
| 번지를 새로 매김 (인천 997필지) | VWorld 필지고유번호변동연혁 | 옛 번지 → 새 번지 공식 짝. 다만 정부 반영이 몇 달 늦다(2026-09-15판에 이 건 없음) |

## Decision

1. **게시판은 원천이 아니다.**
   - code.go.kr 코드변경안내 게시판, 행정안전부 게시판 공지와 첨부는 수집하지도 읽지도 않는다.
   - ADR-0143 §3을 대체한다. ADR-0143의 나머지(code.go.kr 전체 코드 표가 정본, 매일 수집, 형식·감소 거부, 대응표 정본 전환)는 그대로다.
2. **원천은 내려받는 데이터 넷이다.**

   | 데이터 | 쓰는 것 |
   |---|---|
   | code.go.kr 전체 코드 표 | 동 코드·이름·상위 코드·생성일·폐지일 |
   | VWorld 연속지적 필지 (매월) | 동마다의 번지(본번-부번) 집합 |
   | VWorld 필지고유번호변동연혁 | 옛 PNU → 새 PNU 공식 짝 |
   | VWorld 토지이동이력 | 변동 사유·일자 (확인용) |

3. **판단 순서. 모든 단계가 데이터만 본다.**
   1. **동 코드 짝:** 같은 날, 같은 상위 지역에서 폐지된 코드와 생성된 코드가 시도를 뺀 이름으로 하나씩 맞으면 짝이다.
   2. **이름 변경·통합·분리:** 1에서 못 정한 것은 연속지적 두 판의 **번지 집합**으로 정한다.
      - 옛 동의 번지가 다음 판에서 어느 새 동(들)에 있는지 센다.
      - 한 새 동에 기준 이상 모이면 그 동으로 간 것이다(이름 변경·통합).
      - 여러 동으로 나뉘면 분할이다. 번지별로 간 곳을 기록한다.
      - 기준값은 계약 파일 하나에 둔다.
   3. **번지가 새로 매겨진 필지:** 필지고유번호변동연혁의 공식 짝을 쓴다(ADR-0113 계보, 등급 `evidence_strong`).
   4. **남는 것만 사람 확인.** 공식 짝이 아직 나오지 않은 재번호 필지만 남는다. 이들은 면적·지목·소유 일치로 후보를 만든다.
      후보는 자동으로 확정하지 않는다.
   5. **폴리곤(도형)은 어떤 단계에서도 근거가 아니다.**
4. **필요한 데이터가 운영에 없으면 그 판단은 멈춘다.**
   - 연속지적 두 판이나 변동연혁이 아직 적재되지 않았으면 2·3단계는 돌지 않는다.
   - 해당 코드는 "판단 대기"로 남고, 이유와 함께 보고한다.
   - 1단계로 정해진 것은 그대로 쓴다. 이름 규칙만으로 2·3단계의 몫을 추정하지 않는다.

## Consequences

- 공지 양식 변화나 공지 누락이 시스템을 멈추거나 틀리게 하지 않는다.
- 번호만 바뀌는 개편(이번 전남광주 같은 경우)은 코드 표만으로 끝난다.
- 이름 변경·분리는 연속지적 수집과 계보 표(ADR-0113)가 운영에 들어와야 자동이 된다. 그 전까지는 판단 대기다.
- 사람 확인은 "재번호인데 정부 공식 짝이 아직 없는 필지"로 줄어든다.
- 게시판 수집을 만들던 PR #329는 그 부분을 뺀다.
