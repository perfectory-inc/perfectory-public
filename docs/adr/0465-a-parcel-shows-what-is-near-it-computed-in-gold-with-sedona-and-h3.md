# ADR 0465: 필지 화면의 "주변" 은 Gold 에서 Apache Sedona 의 최근접 조인과 H3 칸으로 계산한 자기 by-PNU 종류다

- Status: Accepted
- Date: 2026-11-09
- Builds on: ADR-0401(data.go.kr 파일 데이터 — 물류 5·주변 생활 5), ADR-0453(표준데이터 내려받기), ADR-0193(데이터 종류마다
  Gold 표와 by-PNU 레인), ADR-0287 §9(자기 생산자), ADR-0312 §2(바뀐 키만), ADR-0321 §5(코드·전체 빌드는 키별 발행),
  ADR-0329 §3(법정동 코드 변경을 따라간다), ADR-0435(자동 승격), ADR-0457(첫 run)

## Context

**사고(2026-11-09, 화면 표 `production-readiness` §10).** ADR-0457(#1201)이 `data_go_kr_file_data` 를 켰지만 물류 입지 5(고속도로
출입시설·공항·철도역·도시철도역·항만)와 주변 생활 5(초중등학교·대학·상가·행정동 인구·세대수)가 "없음" 이다. ADR-0401 은 이 표들을
"읽는 소비자가 아직 없어 contract_only" 로 두었다. 산업 부동산 사용자가 물류 입지에서 먼저 묻는 것은 "IC·항만·공항·역까지 얼마나
먼가" 이고, 그 답은 필지마다 다르다.

**원천의 모양(파일 계약 `data-go-kr-file-data.contract.json` 실측, 2026-11-04·09).**

| 파일 | 행 | 위치 |
|---|---:|---|
| 공항 | 14 | 위도·경도(WGS84) |
| 철도역 | 215 | 위도좌표·경도좌표 |
| 도시철도역 | 898 | 위도·경도 |
| 초중등학교 | 12,004 | 위도·경도 |
| 대학 | 1,995 | 좌표 없음 — 도로명 주소가 필지에 이른 것 68.0% |
| 상가(상권) | 2,753,778 | 경도·위도 |
| 고속도로 출입시설 | 844 | 좌표·지번 없음 — 도·시군구·읍면동 이름으로 법정동 코드 |
| 항만 | 72 | 항만위치가 시도·시군구 이름뿐 — 필지도 코드도 없다(파일 계약) |
| 행정동 인구·세대수 | 3,620 / 판 | 행정동 코드, 법정동 연계정보로 법정동에 |

필지는 서빙 필지판 39,861,511 개다. 필지마다 최근접을 손으로 짠 기하로 찾으면 ADR-0375 의 `zone_overlap` 처럼 검증되지 않은 커널을
하나 더 갖게 된다.

### 실사례

- **Apache Sedona** 는 Spark 위의 공간 SQL 표준 구현이다(Apache 최상위 프로젝트; Wherobots·AWS Glue·Databricks 문서가 쓴다).
  `ST_KNN(R, S, k, use_spheroid)` 는 정확한 k-최근접 조인이고, `ST_DistanceSpheroid` 는 WGS84 회전타원체 거리다. H3 함수
  (`ST_H3CellIDs`, `ST_H3KRing`)도 같은 jar 에 있다.
- **H3 칸 집계로 밀도.** Uber 가 H3 를 만든 이유가 "반경 안 개수" 를 칸 합으로 바꾸는 것이다. Foursquare·Carto 의 POI 밀도도 같은
  모양이다. 반경 거리 조인(필지 4천만 × 상가 275만)은 도심에서 쌍이 수십억이 되지만 칸 합은 필지당 칸 19 개다.
- **바뀐 점 둘레만.** 칸 집계는 바뀐 상가의 칸과 그 둘레만 다시 계산하면 된다(공간 색인의 기본 부분 갱신).

## Decision

1. **종류 하나: `parcel-nearby`.** `gold.parcel_nearby`(필지마다 한 행, `nearby_json`)를 자기 생산자
   `parcel_nearby_silver_to_gold` 가 짓고, 필지 호스트가 `/parcels/nearby/by-pnu/` 로 서빙한다. 문서 `nearby`:
   - `airport`·`railway_station`·`subway_station`·`school`·`university`: 가장 가까운 하나의 원천 이름 칸(공항명, 역이름,
     역사명·노선명, 학교명·학교급구분, 학교명·학교구분명)과 `distance_m`(필지 경계 중심에서 회전타원체 거리, 미터). Sedona `ST_KNN`
     (k = 1, spheroid). 대학은 좌표가 없어 주소가 이른 필지의 중심에 선다. 파일에 위치 있는 행이 없으면 null.
   - `commercial_store_count`: 상가 좌표의 H3 칸(해상도 9, 평균 0.105 km²)마다 센 수를 필지 칸 둘레 두 겹(칸 19 개, 약 500 m)에서
     더한 것.
   - `highway_access_points`: 필지 시군구(PNU 앞 다섯 자리)의 출입시설(노선명·출입시설), 최대 20 과 전체 수. 원천에 위치가 없어
     거리는 재지 않는다.
   - 좌표가 숫자가 아니거나 한국 범위(위도 32.5–39.0, 경도 124.0–132.0) 밖이면 원천의 오류로 보고 후보에서 뺀다.
2. **Sedona 는 엔진 계약의 한 블록.** `lakehouse-engine.contract.json` `sedona`(1.9.1, `sedona-spark-shaded-3.5_2.12`,
   `geotools-wrapper` 1.9.1-33.5)를 `lakehouse_engine.iceberg_packages` 가 함께 내므로 릴리스가 jar 를 얼린다(ADR-0134 §3). 세션은
   `with_sedona` 로 확장을 Iceberg 옆에 더한다. CI 의 Spark 런타임(`foundation-spark-runtime.sh`)도 같은 블록을 받는다. Rust 의 Silver
   적재기는 공간 SQL 을 돌지 않아 Iceberg·Hadoop 만 낸다.
3. **부분 처리.** 바뀐 상가(고정한·지금 Silver 의 칸 양방향 차이)는 그 칸 둘레 두 겹 안의 필지만, 들고 나거나 경계가 바뀐 필지는
   그 필지만 다시 계산한다. 시설 파일(공항·철도역·도시철도역·학교·대학·출입시설)과 법정동 코드 변경 표가 바뀌면 통째로 짓고,
   digest 가 달라진 문서만 발행한다(ADR-0321 §5) — **선언한 예외**: 어떤 필지의 최근접이든 바뀔 수 있고, 그 파일들은 14–12,004 행에
   한 해 몇 번 바뀐다.
4. **법정동 코드 변경.** 대학의 PNU 와 출입시설의 법정동 코드를 모든 필지 종류와 같은 `renumbered` 로 서빙 필지판의 코드로 읽는다
   (ADR-0329 §3). 점 파일의 좌표는 코드가 아니어서 따라갈 것이 없다.
5. **이 종류에 넣지 않는 것.** 항만: 원천이 시도·시군구 이름뿐이라 거리를 잴 위치가 없다(ADR-0401 의 결정 그대로). 행정동 인구·
   세대수: 매달 모든 행정동 값이 바뀌어 필지 문서에 넣으면 매달 3,986만 문서가 모두 바뀐다 — 행정동 단위 문서로 따로 서빙할 일이고
   이 ADR 의 범위가 아니다. 법정동 연계정보·필지 ID 원장은 사용자가 읽는 표가 아니다(§10 의 "행정·내부").

## Consequences

- §10 표에서 일곱 줄(공항·고속도로 출입시설·철도역·도시철도역·초중등학교·대학·상가)이 "없음 → 길 있음·꺼짐" 이 된다(정의에서 계산:
  화면 29/68 그대로, 길 있음·꺼짐 13 → 20, 없음 26 → 19). 레인 작업은 꺼져 있다: Silver 표가 아직 없고(2026-11-09, 적재 대기),
  전국 첫 빌드는 ADR-0457 §1 의 길로 켜지지 않는다. 첫 빌드를 잰 뒤 ADR-0435 자동 승격이 발행한다.
- **비용(계산).** 첫 빌드: 필지 3,986만 개의 경계 중심(WKB 파싱 한 번), KNN 조인 다섯, H3 둘레 펼침 7.6억 행과 상가 칸 수 표의
  방송 조인. Gold 3,986만 행, 문서 하나 약 400 바이트(JSON) → 원문 약 16 GB, 법정동 묶음 압축 뒤 수 GB, R2 월 0.1 달러 아래.
  ai-server 에서 돌아 계산 지출 0. 첫 발행은 필지판처럼 전국 굽기라 시간이 길다 — ADR-0435 의 용량·우선순위 스케줄이 시점을 정한다.
- 릴리스가 jar 두 개(82,601,139 + 31,949,894 바이트)를 더 얼린다.
- 거리는 필지 경계 중심 기준이다. 큰 필지는 경계까지보다 길게 나온다. 출입시설은 같은 시군구 목록이라 시군구 경계 바로 너머의 IC 는
  빠진다 — 원천에 위치가 생기면 KNN 으로 옮긴다.
