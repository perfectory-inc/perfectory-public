# Foundation ADR

Foundation Platform의 설계 결정 기록이다. 기존 Foundation 번호는 동결되어 있으며,
새 모노레포 횡단 결정은 루트 `docs/adr/`의 전역 번호를 사용한다.

전체 파일 목록과 상태는 [문서 색인](../../../../docs/document-catalog.md)에서 확인한다.
결정이 바뀌면 기존 ADR을 덮어쓰지 말고 새 ADR과 대체 관계를 기록한다.
