# ADR 0085: 필지는 공시지가 원장에서 값을 배운다

- Status: Accepted
- Date: 2026-09-06

## Context

필지 패널의 공시지가 줄은 값이 있을 때만 그려지는데, 그 값을 만드는 코드가 없다 —
`official_land_price_per_m2` 와 `gosi_year_month` 는 조회 어댑터에서 `None` 하드코딩이다.
용도지역(ADR-0083)과 정확히 같은 모양의 공백이고, 원천도 같은 창고에 이미 있다.

2026-09-06 실측, `bronze/source=vworldkr__land_individual_price/` 68객체 18.5GB:

- 두 갈래가 한 prefix 에 섞여 있다: `20171128DS00143-*`(34객체)는 D150 **DBF**
  (무명 칼럼 A0~A17, 시도당 최대 1.4GB), `20171128DS00144-*`(34객체)는 D151
  **필지별 속성 CSV**(EUC-KR, 명명 칼럼 13개).
- D151 행 = 고유번호(19자리 PNU) · 특수지구분코드/명 · 지번 · **기준연도 · 기준월 ·
  공시지가(원/㎡) · 공시일자** · 표준지여부 · 데이터기준일자 · 원천시도시군구코드.
  패널이 원하는 두 값(가격, 기준연월)이 그대로 있다.
- 빈티지는 완전 규칙: D151 = 17개 시도 × 수확 2회(20260210, 20260526). 최신 20260526 이
  정확히 시도 17개 — "시도별 최신 하나" 선별이 성립한다(ADR-0083 §1 과 동일).

## Decision

1. **`silver.land_individual_price`** 는 D151 속성 CSV 만 싣는다. D150 DBF 는 Bronze 에
   남는 명명 제외다 — 같은 사실의 다른 포장이며, 무명 칼럼을 해석하는 것은 추측이 된다.
   적재기는 시도마다 최신 빈티지 하나를 고르고, 전국 실행은 17개 시도 전부가 아니면
   거부한다. CSV 해석은 ADR-0083 이 만든 레인(공용 배관 + Lane 선언)을 재사용한다 —
   새 레인은 헤더·칼럼 매핑 선언 하나로 늘어난다는 것이 그 결정의 약속이었다.
2. **서빙 정본은 `catalog.parcel_price`**: 필지당 한 행(pnu PK) — 선택 빈티지 안에서
   (기준연도, 기준월)이 가장 최신인 평가액. 가격은 원/㎡ 정수 그대로, 기준연월과
   공시일자를 함께 나른다. 행이 없으면 없다고 답한다(ADR-0078).
3. by-pnu API 응답은 nullable `price` 를 나른다(가격·기준연도·기준월·공시일자).
   화폐 표기·형식화는 소비자(공짱) 몫이다.

## Consequences

- 규모는 필지당 1행 수준(전국 ≈ 4천만 행/빈티지) — 필지 투영과 같은 급이며 같은
  COPY→merge 패턴을 쓴다.
- 이 레인이 공용 배관의 첫 재사용 증명이다: 수출기 추가가 선언 수십 줄로 끝나는지가
  ADR-0083/배관 통합의 실측 검증이 된다.
- 다음 후보 `land_characteristic`(토지특성)도 같은 D-계열이므로 같은 선언 방식으로 탈 수
  있다.
