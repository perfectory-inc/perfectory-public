# Foundation contracts

Foundation이 외부 플랫폼에 공개하는 HTTP·이벤트·식별자 계약의 공유 타입입니다.
계약 변경은 호환성 검토와 해당 OpenAPI/스키마 갱신을 함께 요구합니다.

- 계약 문서: [`docs/openapi/`](../../docs/openapi/)
- 영역 문서: [`docs/README.md`](../../docs/README.md)
- 검증: `cargo test -p foundation-contracts`
