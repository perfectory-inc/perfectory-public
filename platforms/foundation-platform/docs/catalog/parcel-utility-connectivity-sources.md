# 필지 기반시설 인입 가능성 원천 조사(제안)

| 항목 | 내용 |
|---|---|
| 작성일 | 2026-11-11 (W63, 조사만 — 코드 없음) |
| 상태 | 제안(승인 전). 수집 결정은 원천마다 별도 PR·ADR 로 한다 |
| 질문 | 공장·창고 매수·임차인이 "이 필지에 상수도·하수도·도시가스·전력·통신·도로를 끌어올 수 있는가" 를 판단할 공개 자료는 무엇인가 |
| 기계 정본 | 수집이 정해지면 [`public-source-endpoint-catalog.v1.json`](./public-source-endpoint-catalog.v1.json) 에 endpoint 를 더한다. 이 문서는 그 전의 조사 기록이다 |

## 결론

1. **배관·선로 도형 그 자체는 공개되지 않는다.** 상수도·하수도·가스·전력·통신 지하시설물 도형은 국가공간정보
   보안관리규정의 공개제한 공간정보다. 지하공간통합지도 전자파일은 지하안전정보시스템에서 승인받은
   지하개발사업자에게만, 암호화되고 기한이 지나면 지워지는 파일로 나간다(2026-09-30 시행). 우리는 받을 수 없다.
2. **그래서 필지 지표는 "실증 신호 + 구역 + 용량" 으로 만든다.** 이미 가진 자료로 가장 강한 신호 둘을 바로 만들 수 있다.
   - 도시가스: 건축HUB 건물 월별 가스 사용량(이미 Silver)이 그 지번·이웃 지번에 있으면 가스가 들어와 있다는 증거다.
   - 하수도: 건축물대장 오수정화시설(이미 Bronze)이 있는 건물은 공공하수도 대신 개인하수처리시설을 쓴다는 신호다.
   - 도로: 토지특성 `도로접면`(이미 Silver)이 필지별 도로 접면 등급을 준다.
3. **새로 받을 1순위는 한전 분산전원연계정보 API** 다. 공개(인증키)·이용 제한 없음·실시간이고, 지역마다
   변전소·주변압기·배전선로의 연계 용량과 여유 용량을 준다. 공장 입지에서 가장 자주 막히는 전력 여유를 필지에
   붙일 수 있는 유일한 공개 원천이다.
4. **data.go.kr 의 국토교통부 연속주제·도시계획정보 SHP 사본은 받지 않는다.** 공공누리 제4유형(상업적 이용금지·변경금지)이다.
   같은 고시 구역은 이미 받는 브이월드 용도지역지구(NA/24)에 있다.
5. **도시가스 공급구역·통신은 전국 공개 도형이 없다.** 가스는 사용량 실증으로, 통신은 지하시설물 유무 간편 조회로만 본다.

## 필지 지표로 만들 때 지킬 것

- **부분 처리.** 1·2번은 기존 Silver 의 바뀐 지번만 다시 계산한다(by-PNU 패널의 changed-keys 레인과 같다). 이웃 비율은
  법정동 단위로 묶어, 행이 바뀐 법정동만 다시 센다.
- **4번(한전 API)은 전량 조회가 예외로 필요하다.** 원천이 변경 목록을 주지 않는 실시간 값이라 바뀐 지역을 알 길이 없다.
  선언할 예외: 법정동(리) 단위 전량 조회를 정해진 주기로 하고, 응답 해시가 바뀐 지역만 Silver 에 덧붙인다(append-only).
  조회 수는 활성 법정동·리 코드 수(약 2만, 추정 — 수집 PR 이 code.go.kr 표에서 센다)이고, 공공데이터포털 일일 호출 한도
  (보통 개발계정 1만 건, 확인 필요) 안에서 2~3일에 한 바퀴다. 비용은 0원(무료 API), 저장은 수십 MB(계산 아님, 추정).
- **법정동 코드 변경을 따라간다.** 지역 단위로 붙는 4·8번 지표는 적재 때 한 번 풀고 멈추지 않고, ADR-0329 §3
  `views.changed_codes` 에 묶는다.
- **원천 값은 바꾸지 않는다.** 5번(공공누리 제3유형 변경금지)은 단지 값을 그대로 싣고, 우리 계산 지표와 칸을 나눈다.
- **확정이 아니라 추정임을 표시한다.** 공개 자료로는 "인입 가능" 을 확정할 수 없다(한전도 실제 공급 가능 여부는 전기사용신청 뒤
  확정한다고 적는다). 지표는 "실적 있음/신호 있음/자료 없음" 으로 쓰고, 단정 문구를 쓰지 않는다.
