# ADR 0113: 필지 계보가 지역 개편·합병·분할을 코드로 흡수하고, 모든 지도 굽기 앞에서 폴리곤 매칭을 검문한다

- Status: Accepted
- Date: 2026-09-29
- Builds on: [ADR-0103](./0103-place-identity-outlives-administrative-code-changes.md)(안정 ID·시간 사전·해석기·스튜어드),
  [ADR-0104](./0104-the-authority-api-is-current-only-so-the-crosswalk-comes-from-snapshot-diffs.md)(스냅숏 차이),
  [ADR-0105](./0105-the-canonical-transition-table-is-produced-from-the-derived-crosswalk.md)(전이표),

## Context

2026-07-01 에 두 개편이 동시에 시행됐다. 광주(29)+전남(46) → 전남광주통합특별시(12), 인천 중구·동구·서구 →
제물포구(28125)·영종구(28155)·서해구(28275)·검단구(28290). 2026-09 원천은 이미 새 코드로 온다.
2026-09-29 에 **코드만으로**(폴리곤은 근거에서 제외) 실측한 사실:

| 대상 | 7월 필지 | 같은 지번·새 코드로 이어짐 | 사라짐 / 생김 | 9월 필지 |
|---|---:|---:|---:|---:|
| 광주+전남 → 12 | 6,315,425 | 6,303,927 (99.82%) | 11,498 / 6,773 | 6,310,700 |
| 인천 전체 | 667,468 | 665,283 (99.67%) | 2,185 / 2,504 | 667,787 |

- 두 경우 모두 `7월 − 사라짐 + 생김 = 9월` 이 정확히 성립한다. 사라짐·생김의 대부분은 토지이동이력에 사유가
  적힌 평소 변동(합병·분할·지적재조사·등록전환)이다. 광주+전남은 사유 미확인 916(0.015%), 인천은 1,058
  (지적재조사 지구·지도 반영 지연으로 보이나 인천은 미검증).
- 법정동 수준: 공식 법정동코드 전체자료(존재/폐지)에서 (시군구명, 동명)으로 광주+전남 2,947개 동 전부 1:1,
  인천 80개 동 중 78개 1:1. 동명이 겹치는 금곡동 2개는 지번 겹침률(100%)로 갈린다.
- **인천 997필지**(옛 서구 시천동·오류동 일부 → 서해구 검암동 875·경서동 122)는 지번까지 새로 매겨졌다.
  토지이동이력은 7/1 "행정관할구역변경"으로 이 997개 **새 번호**를 정확히 싣지만 옛 번호는 없다.
  필지고유번호변동연혁(VWorld 30527, 인천 2026-09-15판)의 7/1 기록은 중구→제물포구 동 단위 44건뿐이다.
  건축물대장 고유번호 연속성으로 78개가 옛 번호와 이어지고, 면적(0.1㎡)·지목·소유구분·공유인수가 모두
  맞는 유일한 짝이 그 78개 중 77개와 일치했다(불일치 1은 대장의 "산 0-0" 오기).
- **위험:** 9월 지도 폴리곤은 새 번호인데 공시지가·토지특성·소유 파일은 2026-05-26 이 최신이라 옛 번호다.
  그대로 붙이면 인천 폴리곤 132,613개(19.9%)의 공시지가가 빈다. 옛·새 연결을 거치면 전부 붙고, 남는
  빈칸은 정부 공시지가가 원래 없는 땅(4.0%)과 기준일 이후 생긴 필지(0.25%)뿐이다.
- 설계 문서(`docs/reference/geography-identity-wave1-technical-design.md` §4)의 필지 계보 DAG 는 표 모양까지
  있으나 구현이 없다. ADR-0103 은 동 수준 해석기를 정했지만 필지 수준 연결과 지도 매칭 검문은 정하지 않았다.

원천별로 무엇을 주고 무엇을 주지 않는가(실물 확인):

| 원천 | 주는 것 | 주지 않는 것 |
|---|---|---|
| 법정동코드 전체자료(code.go.kr, 키 불필요) | 코드·전체 이름·존재/폐지 | 날짜·후속 코드 |
| 연속지적 필지(VWorld 30563) | 스냅숏의 PNU 전수 | 변동 사유 |
| 토지이동이력(VWorld 13, 시도 월별 AL + 전국 일별 CH) | 필지별 사유코드·일자·말소일자, 합병·분할 상대 지번 문구 | 관할이동·재지번의 옛 번호 |
| 필지고유번호변동연혁(VWorld 30527) | 옛 PNU → 새 PNU 공식 짝 | 반영이 수개월 늦음 |
| 건축물대장(HUB) | 건물 고유번호 연속성(건물 있는 필지) | 건물 없는 필지 |
| 토지대장 조회(NED `ladfrlList`) | 현행 면적·지목·소유구분·공유인수 | 폐쇄된 옛 번호(0건) |

## Decision

1. **필지 계보 표를 레이크하우스 정본으로 둔다.** `silver.parcel_lineage` — 한 행이 "옛 PNU → 새 PNU" 하나다.
   칸: `predecessor_pnu, successor_pnu, relation, effective_date, grade, evidence_kind, evidence_ref,
   derived_at_utc, derivation_run_id`. `relation ∈ {code_change, merge, split, jurisdiction_transfer, resurvey,
   registration_conversion, other}`. 덮어쓰지 않고 쌓는다(append-only). 시험: 같은 입력으로 두 번 돌리면 새
   행이 0개이고, 근거가 바뀌면 새 행이 붙을 뿐 옛 행은 남는다.

2. **등급은 근거로만 정하고, 높은 등급이 효력을 가진다.** 도출 규칙과 등급(높은 순):
   - `official` — 필지고유번호변동연혁의 짝, 토지이동이력의 합병·분할 문구가 가리키는 같은 동 안의 지번.
   - `code_derived` — (a) 같은 지번 + 공식 코드목록으로 1:1 대응된 법정동, (b) 건축물대장 고유번호가
     개편 전후 스냅숏에서 같은 건물.
   - `evidence_strong` — 면적(0.1㎡)·지목·소유구분·공유인수가 모두 같고 양쪽에서 유일한 짝.
   - `evidence_weak` — 면적·지목이 유일하게 같되 소유 자료가 없거나, 소유로 동률을 가른 짝.
   - `needs_review` — 면적·지목은 유일하게 같은데 소유가 다른 짝.
   - `pending` — 짝 없음.
   효력 연결 = 한 옛 PNU 에 대해 가장 높은 등급의 행. 높은 등급이 낮은 등급과 다른 짝을 가리키면 경보를 낸다.
   **폴리곤 겹침·포함은 어떤 등급의 근거도 아니다.** 시험: 폴리곤만 일치하는 짝을 심으면 `pending` 에 머문다.

3. **법정동 대응은 공식 코드목록의 연속 스냅숏에서 나온다(ADR-0104 확장).** 코드목록은 (코드, 전체 이름,
   존재/폐지)만 주므로 대응 규칙은: 같은 날 폐지된 코드와 새로 존재하게 된 코드 사이에서 (시군구명, 동명)
   일치 → 없으면 동명 유일 일치 → 그래도 동률이면 지번 겹침률이 더 높은 쪽. 동 대응은 계보의 `code_change`
   를 만드는 입력이며, 지번 겹침률이 95% 미만인 동 대응은 분할 신호로 보고 해당 동의 사라진 지번만 2항의
   증거 규칙으로 넘긴다(시천동: 겹침 37.8% → 871 지번이 증거 규칙으로).

4. **속성 붙이기는 효력 연결을 거친다.** 폴리곤(현재 지도 스냅숏의 PNU)에 붙는 모든 속성은 그 속성의
   기준 시점 PNU 로 들어오므로, 속성 PNU 가 현재 지도에 없으면 효력 연결을 따라가 붙인다. 붙은 경로
   (`same_pnu | lineage:<grade>`)를 서빙 행에 남긴다. `evidence_*` 로 붙은 값은 화면에서 구분할 수 있어야 한다.

5. **모든 필지·행정경계 굽기 앞에 매칭 검문을 둔다.** 굽기(ADR-0112)는 다음을 통과해야 한다:
   (a) 모든 폴리곤의 법정동이 공식 코드목록에서 "존재"이고 그 읍면동에 경계가 있다 — 위반 0;
   (b) 스냅숏 간 `전 − 사라짐 + 생김 = 후` 가 성립한다;
   (c) 속성 빈칸은 허용 사유(원천에 값이 없음, 기준일 이후 생김, 계보 `pending`)로만 설명되고, 허용 사유
   밖의 빈칸이 0 이다. 위반이 있으면 굽지 않고 슬랙에 사유별 개수를 보낸다. 매일 같은 대사를 돌려 사유
   미확인 목록을 남기고 다음 원천이 오면 다시 확인한다. 시험: 속성 PNU 하나를 옛 코드로 바꿔 심으면 계보가
   없을 때 검문이 거부하고, 계보를 넣으면 통과한다.

6. **행정경계 id 는 코드가 아니라 승계 사슬의 첫 코드에 묶는다(ADR-0112 개정).** ADR-0112 이행에서 쓴
   `uuid5("scope:legal-dong:" + 현재 코드)` 는 코드가 바뀌면 id 가 바뀌어 ADR-0103 1항을 어긴다. 새 규칙은
   `uuid5("scope:legal-dong:" + 사슬의 가장 이른 코드)` 이고 사슬은 3항의 동 대응이 만든다. 표시(이름·코드)는
   항상 현행이다. 시험: 광주 동구 학동(2911012200)과 전남광주 동구 학동(1221012200)이 같은 id 를 갖는다.

7. **사람은 `needs_review`·`pending` 만 본다.** 스튜어드 결정은 코드가 아니라 계보 행(`evidence_kind =
   steward`, 결정자·근거·시각)으로 쌓인다(ADR-0103 4항). 매일 슬랙 요약: 새 개편 감지, 등급별 건수 변화,
   검문 결과.

8. **수집은 이 ADR 의 범위 밖이다.** 위 표의 원천(특히 법정동코드 전체자료, 30527, 토지이동이력 CH/AL,
   건축물대장 월별)을 매일 받는 일은 수집 레인이 한다. 이 ADR 의 도출은 Bronze 에 있는 것만 읽고, 원천이
   늦으면 등급이 늦게 오를 뿐 잘못된 연결을 만들지 않는다.

## Consequences

- 지역 개편·합병·분할·지적재조사가 같은 경로로 흡수된다. 개편 때 엔지니어가 할 일은 없고, 사람은
  `needs_review`·`pending` 만 본다. 이번 개편 기준 인천 997필지 중 `code_derived` 78, 증거 등급 약 770,
  `needs_review` 65, `pending` 89 로 시작한다(2026-09-29 측정).
- 굽기가 매칭 검문을 통과해야 하므로, 옛 코드 속성이 새 코드 지도에 안 붙어 "가격이 빈 지역"이 생기는
  사고(인천 기준 19.9%)가 운영에 나가지 않는다.
- 비용: 계보 도출 Spark 작업(스냅숏 쌍마다), 속성 붙이기 경로의 계보 조인, 검문 단계, 스튜어드 목록.
  속성 파일마다 기준 시점 PNU 를 유지해야 한다(현재 Silver 는 이미 원천 PNU 를 보존한다).
- ADR-0112 로 올라간 행정경계 서빙본(`gold.administrative_boundary_served`)은 6항 규칙으로 id 를 다시 계산해야
  한다. 7월 스냅숏은 개편 전 코드가 곧 사슬의 첫 코드이므로 id 가 그대로이고, 9월 스냅숏을 들일 때부터
  차이가 난다.
- 후속: 계보 표 계약·도출 작업(1–3항), 행정경계 9월 스냅숏과 id 개정(6항), 검문(5항), 속성 붙이기(4항),
  스튜어드 목록(7항) 순으로 PR 을 나눈다.
