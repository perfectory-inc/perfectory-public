# ADR 0093: 대지권의 정체성은 호 단위다

- Status: Accepted
- Date: 2026-09-07

## Context

ADR-0091 은 `catalog.parcel_land_right` 의 서빙 키를 `(pnu, right_serial_no)` 로 정했고,
한 vintage 안의 키 중복은 적재 전체를 거부하도록 했다. 2026-09-07 전국 27,798,377행
(AL_D006, vintage 20260609)을 처음 투영하자 스테이지 단계에서 그 거부가 실제로 일어났다.

Trino 로 silver 실물을 전수 측정한 결과:

- `(pnu, right_serial_no)` 조합은 **436,190개** — 행 64개당 1개로, 행의 정체성이 아니다.
- `right_serial_no` 는 전국에 **6,094종**뿐이며 "0001"(981,487행), "0002"(854,455행) 순으로
  분포하는 **필지 안 일련번호**다. 필지(427,993개)당 평균 1.02개 존재한다.
- `(pnu, 동, 층, 호, 실)` 조합은 **27,707,930개**로 전체의 99.67% — 대지권 행의 실물
  정체성은 **전유부(호)** 다. 예: 서울 헬리오시티 필지는 `(pnu, "0969")` 한 조합 아래
  101동 704호·801호·802호… 가 각자의 지분율(`37.6972/346570.4`)을 가진 행으로 존재한다.
- 잔여 중복: 완전 동일 행 약 4.2만(제공자 원천 중복), 같은 호에 속성만 다른 그룹 약
  4.9만(지분율·폐쇄 구분 변형) — ADR-0090 이 이동이력에서 확인한 것과 같은 부류다.

또한 호 단위 행이 되면 한 필지의 `land_rights` 가 수천~1만 행에 이르므로(헬리오시티급),
by-pnu 응답에 전량을 싣는 기존 계약은 패널 응답 크기·지연 사고를 예약해 둔 것과 같다.

## Decision

1. `catalog.parcel_land_right` 의 기본 키를
   `(pnu, right_serial_no, dong_name, floor_name, ho_name, room_name)` 로 바꾼다.
   호 지정 4칸(`dong_name`, `floor_name`, `ho_name`, `room_name`)은 `NOT NULL DEFAULT ''` 로
   승격하고, 핸드오프의 결측은 적재기가 빈 문자열로 정규화한다. 이 항은 ADR-0091 의
   키 조항을 대체한다(supersede). ADR-0091 의 나머지(레인·계약·Silver 원문 보존)는 유지된다.
2. 투영 스테이지는 제약 없이 받는다(`INCLUDING DEFAULTS` 만). 병합은 결정적 접기로 한다:
   키 6칸 + 나머지 값 칸 전체를 정렬 기준으로 한 `DISTINCT ON` + `ON CONFLICT DO NOTHING`.
   같은 키에 값이 다른 그룹 수(`conflicting_groups`)를 세어 요약 로그로 남긴다.
   원문 전 행은 Silver 가 보존하므로 접기는 서빙 투영에서만 일어난다.
3. by-pnu 의 `land_rights` 는 결정적 정렬(일련번호→동→층→호→실)의 **앞 200행**으로
   상한하고, 전체 행 수를 `land_right_total` 로 함께 싣는다. 두 값은 한 질의(윈도 함수)로
   읽는다.
4. 적재 요약 로그는 `input_rows / staged / inserted / collapsed_or_existing /
   conflicting_groups` 를 보고한다(ADR-0090 과 동일한 형).

## Consequences

- 대지권이 전유부 단위로 서빙되어, 건물 3층 계보(ADR-0074/0075)의 호와 필지 지분을 잇는
  다리가 된다. 후속으로 호 매칭(동·호 정규화 조인)이 가능해진다.
- 거부 대신 접기가 되므로 제공자 원천 중복(~0.3%)이 적재를 막지 않고, 접힌 수는 로그로
  남아 대사가 가능하다.
- 응답 상한 200 은 패널에 충분하고(대다수 필지는 수십 행 이하) 헬리오시티급에서도 응답이
  유계다. 전량이 필요한 소비자는 `land_right_total` 로 절단 여부를 알 수 있다.
- 마이그레이션은 빈 표 재키잉이라 무중단이다. OpenAPI 계약에 `land_right_total` 필드가
  추가된다(`#[serde(default)]` 로 하위 호환).
