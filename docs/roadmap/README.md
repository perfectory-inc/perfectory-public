# 전역 작업 목록

미완료 작업의 정본이다. 작업을 다른 README나 ADR에 복사하지 않는다.

- [운영 준비 작업 목록](./production-readiness.md) — 출시 전에 **무엇을 해야 하는가**
- [기반 목표](./foundation-goals.md) — **무엇이 참이어야 하고, 무엇이 그것을 계속 재는가**

두 문서는 축이 다르다. 작업 항목은 앞의 것이, 불변식과 지표는 뒤의 것이 소유한다. 같은 목록을
둘 다 들지 않는다.

완료된 결정은 ADR로 옮기고, 실제 실행 절차는 runbook으로 옮긴 뒤 이 목록에서 체크한다.
